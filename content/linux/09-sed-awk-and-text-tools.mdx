Unix text tools each do one small job. Joined with pipes, they answer
questions like "which IP sent the most requests?" or "what is the total
salary per department?" without writing a program. The examples use this
`employees.csv` for a fictional company, Tarang Tech (salaries in ₹ per year):

```text
id,name,dept,city,salary
101,Asha Rao,Engineering,Pune,1800000
102,Vikram Shah,Sales,Mumbai,950000
103,Meera Iyer,Engineering,Bengaluru,2400000
104,Rohan Das,Support,Pune,600000
105,Kavya Nair,Engineering,Pune,1500000
106,Arjun Mehta,Sales,Delhi,1100000
```

plus the `access.log` web log from "grep & Regular Expressions".

## cut: pick columns

```bash
cut -d, -f2,3 employees.csv | head -3    # -d delimiter, -f fields
# name,dept
# Asha Rao,Engineering
# Vikram Shah,Sales
```

`cut -c1-3` cuts characters instead of fields. `cut` accepts only a
single-character delimiter and treats every delimiter as a new field, so it
cannot handle columns separated by runs of spaces. Use `awk` for that.

## tr and wc

`tr` translates, squeezes or deletes characters (stdin only); `wc` counts
lines, words and bytes:

```bash
echo "Hello World" | tr 'a-z' 'A-Z'   # HELLO WORLD
echo "a,,b" | tr -s ','               # a,b   (squeeze repeats)
echo "a1b2" | tr -d '0-9'             # ab    (delete)
wc -l employees.csv                   # 7 employees.csv
wc -l < employees.csv                 # 7   (no filename when reading stdin)
```

## sort and uniq

```bash
tail -n +2 employees.csv | sort -t, -k5,5nr | head -2   # highest salary first
# 103,Meera Iyer,Engineering,Bengaluru,2400000
# 101,Asha Rao,Engineering,Pune,1800000
```

| sort flag | Meaning |
|---|---|
| `-n` | numeric sort (otherwise "10" sorts before "9") |
| `-r` | reverse |
| `-t,` | field separator |
| `-k5,5` | sort on field 5 only (`-k5` alone means "field 5 to end of line") |
| `-h` | human sizes like `2K`, `1G` (useful with `du -h`) |

`tail -n +2` skips the header. Without it, `sort -n` treats the text
"salary" as 0 and puts the header first. Multiple keys sort by city, then
salary descending: `sort -t, -k4,4 -k5,5nr`.

`uniq` removes **adjacent** duplicates only, which is why it nearly always
follows `sort` (`sort -u` does both in one step):

```bash
# outputs shown on one line to save space; each value prints on its own line
printf 'b\na\nb\nc\na\n' | uniq          # b a b c a  -- nothing removed
printf 'b\na\nb\nc\na\n' | sort | uniq   # a b c
```

`uniq -c` prefixes a count, giving the most famous pipeline in Unix:

```bash
tail -n +2 employees.csv | cut -d, -f3 | sort | uniq -c | sort -rn
#       3 Engineering
#       2 Sales
#       1 Support
```

## sed: the stream editor

`sed` applies editing commands to each line as it streams past. The command
you will use 90% of the time is substitution, `s/old/new/flags`:

```bash
echo "a-b-c" | sed 's/-/+/'       # a+b-c   first match on each line
echo "a-b-c" | sed 's/-/+/g'      # a+b+c   g = every match
sed -n '2,3p' employees.csv       # -n: print nothing unless told; p = print
# 101,Asha Rao,Engineering,Pune,1800000
# 102,Vikram Shah,Sales,Mumbai,950000
sed '/^#/d; /^$/d' app.conf       # delete comment and blank lines
```

Any character can be the delimiter, which avoids escaping slashes in paths.
With `-E`, parentheses capture groups that you reuse as `\1`, `\2`:

```bash
echo "path /usr/local/bin" | sed 's#/usr/local#/opt#'    # path /opt/bin
echo "2026-10-14" | sed -E 's/([0-9]{4})-([0-9]{2})-([0-9]{2})/\3\/\2\/\1/'
# 14/10/2026
```

### Editing files in place

`sed -i` overwrites the file. Give it a suffix to keep a backup, and always
run the command once **without** `-i` to check the output first:

```bash
sed -i.bak 's/^port=.*/port=9090/' app2.conf
grep port app2.conf app2.conf.bak
# app2.conf:port=9090
# app2.conf.bak:port=8080
```

On macOS (BSD sed), `-i` always takes a suffix argument (`sed -i ''` for no
backup), so `-i.bak` is the portable form.

## awk: a small language for columns

awk splits each line into fields `$1`, `$2` … (`$0` is the whole line) on
whitespace by default. A program is a list of `pattern { action }` pairs.

```bash
awk '{print $1, $9}' access.log | head -2      # IP and status code
# 10.0.0.5 200
# 10.0.0.7 401
awk -F, 'NR>1 && $3=="Engineering" {print $2, $5}' employees.csv
# Asha Rao 1800000
# Meera Iyer 2400000
# Kavya Nair 1500000
```

| Built-in | Meaning |
|---|---|
| `NR` | current line (record) number |
| `NF` | number of fields on this line; `$NF` is the last field |
| `-F,` or `FS` | input field separator |
| `OFS` | output separator, e.g. `-v OFS=';'` |
| `BEGIN { }` / `END { }` | run before the first / after the last line |

`END` blocks and associative arrays make awk a reporting tool:

```bash
awk '{bytes+=$NF} END {print "total bytes:", bytes, "lines:", NR}' access.log
# total bytes: 1625 lines: 8
awk -F, 'NR>1 {sum[$3]+=$5} END {for (d in sum) printf "%-12s %10d\n", d, sum[d]}' employees.csv | sort
# Engineering     5700000
# Sales           2050000
# Support          600000
```

`for (d in sum)` visits keys in no guaranteed order, hence the final `sort`.

## Interview angles

- **"Top 5 IPs in an access log?"**
  `awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -5`.
  Explain why `sort` must come before `uniq -c`.
- **"Replace a string in every file?"** `sed -i` with `find` (see "Finding
  Files with find & xargs"), after a dry run, with version control as backup.
- **Caveat to mention:** `cut` and `awk -F,` break on real CSV with quoted
  commas such as `"Rao, Asha"`. Use a CSV-aware tool for that.

### Try it yourself

1. Print the average salary of all employees with one `awk` command (hint:
   sum and count in the main block, divide in `END`; it should print 1391667
   when formatted with `%.0f`).
2. List every distinct city, one per line, alphabetically, using `cut`,
   `sort` and `uniq` (or `sort -u`).
3. Use `awk` on `access.log` to count how many requests returned each status
   code, sorted with the most frequent first.
