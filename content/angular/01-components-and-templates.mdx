An Angular component pairs a TypeScript class with an HTML template. Modern
Angular (v17+) defaults to **standalone components** — no `NgModule`
boilerplate required.

```ts
import { Component, signal } from "@angular/core";

@Component({
  selector: "app-greeting",
  standalone: true,
  template: `<h1>Hello, {{ name() }}!</h1>`,
})
export class GreetingComponent {
  name = signal("Asha");
}
```

## Data binding, four ways

```html
<!-- Interpolation: class property -> DOM text -->
<p>{{ title }}</p>

<!-- Property binding: class property -> DOM property -->
<img [src]="imageUrl" />

<!-- Event binding: DOM event -> class method -->
<button (click)="increment()">+1</button>

<!-- Two-way binding: combines property + event binding -->
<input [(ngModel)]="username" />
```

Two-way binding with `ngModel` requires importing `FormsModule` into the
component's `imports` array (standalone components declare their own
dependencies explicitly):

```ts
@Component({
  selector: "app-name-field",
  standalone: true,
  imports: [FormsModule],
  template: `<input [(ngModel)]="username" />`,
})
export class NameFieldComponent {
  username = "";
}
```

## `@Input()` and `@Output()`: parent-child communication

```ts
@Component({
  selector: "app-badge",
  standalone: true,
  template: `<span class="badge">{{ label }}</span>`,
})
export class BadgeComponent {
  @Input() label = "";
}
```

```ts
@Component({
  selector: "app-todo-item",
  standalone: true,
  template: `
    <li>
      {{ text }}
      <button (click)="remove.emit(id)">Delete</button>
    </li>
  `,
})
export class TodoItemComponent {
  @Input() id!: number;
  @Input() text = "";
  @Output() remove = new EventEmitter<number>();
}
```

The parent listens with normal event binding: `<app-todo-item (remove)="onRemove($event)" />`.
