BFS, DFS and shortest paths answer "how do I get from A to B?". The
algorithms here answer **structural** questions: what is the cheapest way
to connect everything, which groups of nodes can all reach each other, and
which single link or node, if it fails, splits the network? They are
standard in senior interviews and in real network, logistics and
dependency-analysis work.

## Minimum spanning tree (MST)

Given a connected, undirected, weighted graph, an MST is a subset of
`V - 1` edges that connects every vertex with the **minimum total weight**.
Example: a state government wants to lay fibre between five villages at the
lowest cost (weights in ₹ lakh).

```text
edges sorted by cost (₹ lakh)   Kruskal decision
1-2 : 1                        take
1-3 : 2                        take
3-4 : 2                        take
0-2 : 3                        take  -> 4 edges = V - 1, stop
0-1 : 4                        (would close cycle 0-1-2)
2-3 : 4                        (would close cycle 1-2-3)
2-4 : 5                        (would close a cycle)

MST:  0 --3-- 2 --1-- 1 --2-- 3 --2-- 4      total = 8
```

Both classic algorithms rest on the **cut property**: for any split of the
vertices into two groups, the cheapest edge crossing the split belongs to
some MST. That is why the greedy choice is safe (compare "Greedy
Algorithms").

### Kruskal: sort edges, add if no cycle

Sort edges by weight and add each one unless it joins two vertices already
connected. Detecting that is exactly what union-find does (see "Topological
Sort & Union-Find" for how it works).

```js
class DSU {
  constructor(n) { this.parent = Array.from({ length: n }, (_, i) => i); this.rank = new Array(n).fill(0); }
  find(x) { while (this.parent[x] !== x) { this.parent[x] = this.parent[this.parent[x]]; x = this.parent[x]; } return x; }
  union(a, b) {
    let ra = this.find(a), rb = this.find(b);
    if (ra === rb) return false;
    if (this.rank[ra] < this.rank[rb]) [ra, rb] = [rb, ra];
    this.parent[rb] = ra;
    if (this.rank[ra] === this.rank[rb]) this.rank[ra]++;
    return true;
  }
}

function kruskal(n, edges) {
  const dsu = new DSU(n);
  const mst = []; let cost = 0;
  for (const [u, v, w] of [...edges].sort((a, b) => a[2] - b[2])) {
    if (dsu.union(u, v)) { mst.push([u, v, w]); cost += w; if (mst.length === n - 1) break; }
  }
  return mst.length === n - 1 ? { cost, mst } : null; // null: graph is disconnected
}
const edges = [[0, 1, 4], [0, 2, 3], [1, 2, 1], [1, 3, 2], [2, 3, 4], [3, 4, 2], [2, 4, 5]];
console.log(kruskal(5, edges));
// { cost: 8, mst: [ [ 1, 2, 1 ], [ 1, 3, 2 ], [ 3, 4, 2 ], [ 0, 2, 3 ] ] }
```

**Complexity:** `O(E log E)` for the sort; union-find operations are nearly
`O(1)` amortised. Space `O(V + E)`.

### Prim: grow one tree

Start from any vertex and repeatedly add the cheapest edge leaving the
tree. With a min-heap (see "Heaps & Priority Queues") that is
`O(E log V)`; for **dense** graphs an array scan gives `O(V^2)` with no heap
at all:

```js
function primDense(n, edges) {
  const W = Array.from({ length: n }, () => new Array(n).fill(Infinity));
  for (const [u, v, w] of edges) { W[u][v] = Math.min(W[u][v], w); W[v][u] = Math.min(W[v][u], w); }
  const inTree = new Array(n).fill(false);
  const best = new Array(n).fill(Infinity); // cheapest edge linking each vertex to the tree
  best[0] = 0;
  let cost = 0;
  for (let k = 0; k < n; k++) {
    let u = -1;
    for (let v = 0; v < n; v++) if (!inTree[v] && (u === -1 || best[v] < best[u])) u = v;
    if (best[u] === Infinity) return null; // disconnected
    inTree[u] = true; cost += best[u];
    for (let v = 0; v < n; v++) if (!inTree[v] && W[u][v] < best[v]) best[v] = W[u][v];
  }
  return cost;
}
console.log(primDense(5, edges)); // 8
```

| | Kruskal | Prim (heap) | Prim (array) |
|---|---|---|---|
| Time | `O(E log E)` | `O(E log V)` | `O(V^2)` |
| Best for | sparse graphs, edge lists | adjacency lists | dense graphs, e.g. all-pairs "connect points" |

Interviewers often ask the "connect all points with minimum cable" problem
where every pair is an edge (`E` is about `V^2 / 2`): array-based Prim
avoids building and sorting that huge edge list.

## Strongly connected components (SCC)

In a **directed** graph, an SCC is a maximal set of vertices where every
vertex can reach every other. Example: one-way highway links between
cities; within an SCC a truck can go anywhere and come back.

**Kosaraju's algorithm** in two DFS passes:

1. DFS the graph, pushing each vertex onto `order` when it **finishes**.
2. Reverse every edge. Process vertices in reverse finish order; each DFS
   on the reversed graph collects exactly one SCC.

```js
function kosaraju(n, edges) {
  const g = Array.from({ length: n }, () => []), rg = Array.from({ length: n }, () => []);
  for (const [u, v] of edges) { g[u].push(v); rg[v].push(u); }
  const order = [], seen = new Array(n).fill(false);
  const dfs1 = (u) => { seen[u] = true; for (const v of g[u]) if (!seen[v]) dfs1(v); order.push(u); };
  for (let i = 0; i < n; i++) if (!seen[i]) dfs1(i);
  const comp = new Array(n).fill(-1); let c = 0;
  const dfs2 = (u) => { comp[u] = c; for (const v of rg[u]) if (comp[v] === -1) dfs2(v); };
  for (let i = n - 1; i >= 0; i--) { const u = order[i]; if (comp[u] === -1) { dfs2(u); c++; } }
  return { count: c, comp };
}
// 0 Mumbai, 1 Pune, 2 Nashik form a loop; 3 Surat, 4 Vadodara, 5 Ahmedabad form another
console.log(kosaraju(6, [[0, 1], [1, 2], [2, 0], [2, 3], [3, 4], [4, 5], [5, 3]]));
// { count: 2, comp: [ 0, 0, 0, 1, 1, 1 ] }
```

`O(V + E)` time and space. Collapsing each SCC to one node yields a DAG
(the **condensation**), which you can then topologically sort. Tarjan's
algorithm finds SCCs in a single pass using low-link values; Kosaraju is
easier to get right under interview pressure.

## Bridges and articulation points

In an undirected graph, a **bridge** is an edge whose removal disconnects
the graph; an **articulation point** (cut vertex) is such a vertex. Think
"single points of failure" in a courier network.

Tarjan's idea: during DFS, `tin[u]` is the discovery time and `low[u]` is
the earliest discovery time reachable from `u`'s subtree using **at most
one back edge**. For a tree edge `u-v`:

- `low[v] > tin[u]` means `v`'s subtree cannot reach `u` or above without
  that edge, so `u-v` is a **bridge**.
- `low[v] >= tin[u]` (and `u` is not the root) means `u` is an
  **articulation point**. The root is one only if it has 2 or more DFS children.

```js
function bridgesAndCuts(n, edges) {
  const adj = Array.from({ length: n }, () => []);
  edges.forEach(([u, v], id) => { adj[u].push([v, id]); adj[v].push([u, id]); });
  const tin = new Array(n).fill(-1), low = new Array(n).fill(0);
  const bridges = [], cuts = new Set(); let timer = 0;
  const dfs = (u, parentEdge) => {
    tin[u] = low[u] = timer++;
    let children = 0;
    for (const [v, id] of adj[u]) {
      if (id === parentEdge) continue;                       // skip the edge we came in on
      if (tin[v] !== -1) { low[u] = Math.min(low[u], tin[v]); continue; } // back edge
      dfs(v, id); children++;
      low[u] = Math.min(low[u], low[v]);
      if (low[v] > tin[u]) bridges.push([u, v]);
      if (parentEdge !== -1 && low[v] >= tin[u]) cuts.add(u);
    }
    if (parentEdge === -1 && children > 1) cuts.add(u);
  };
  for (let i = 0; i < n; i++) if (tin[i] === -1) dfs(i, -1);
  return { bridges, cuts: [...cuts] };
}
// triangle 0-1-2, edge 2-3, triangle 3-4-5, edge 5-6
console.log(bridgesAndCuts(7, [[0, 1], [1, 2], [2, 0], [2, 3], [3, 4], [4, 5], [5, 3], [5, 6]]));
// { bridges: [ [ 5, 6 ], [ 2, 3 ] ], cuts: [ 5, 3, 2 ] }
```

`O(V + E)` time. Skipping by **edge id** rather than parent vertex keeps
parallel edges correct. This is the "critical connections in a network"
interview problem.

## Common mistakes

- Running Kruskal without checking that `V - 1` edges were picked
  (disconnected input).
- Using MST to find shortest paths. An MST minimises total wiring, not the
  distance between two specific nodes — use Dijkstra for that.
- In Kosaraju, processing the second pass in the original order instead
  of reverse finish order.
- Recursion depth: JavaScript's call stack overflows on deep DFS (the limit
  depends on the engine and frame size, typically thousands to tens of
  thousands of frames). For large
  graphs, convert to an iterative DFS.
