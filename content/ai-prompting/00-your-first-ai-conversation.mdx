Reading about AI assistants only goes so far; the fastest way to learn is to
have a conversation with one. This lesson walks you through your first
session step by step. It uses Claude as the example, but almost every chat
assistant works the same way, so the habits transfer.

## Step 1: Get access the right way

Before you open any AI website, check with your manager or IT team which
tool your company has **approved**, and how to sign in. Many companies
provide a work account (often signed in with your office email) that comes
with stronger data protection than a free personal account.

- If your company has an approved tool, use that — not a personal account.
- If there is no approved tool yet, practise only with made-up,
  non-confidential examples like the ones in this course.
- Never share your login with others; your conversations may contain work
  information.

## Step 2: Find your way around the screen

Chat assistants look different from one another, but most have the same
basic parts:

| Part of the screen | What it does |
| --- | --- |
| Message box | Where you type your prompt; press Enter or the send button |
| New chat button | Starts a fresh conversation with no memory of the current one |
| Chat history list | Your earlier conversations, so you can return to them |
| Attach button (often a paperclip or plus sign) | Adds a file such as a PDF, image or spreadsheet |
| Copy button under each reply | Copies the response so you can paste it elsewhere |
| Retry or edit options | Ask again for a different answer, or change what you asked |

Exact names and icons vary between tools and versions, so spend two minutes
hovering over the buttons before you start.

## Step 3: Send your first prompt

Start with something low-stakes and useful. Notice that the improved prompt
below simply tells the assistant **who it is for, what you need and how long
it should be** — the same things you would tell a new colleague.

A vague first attempt:

```text
Write about team lunch.
```

A clearer version for a fictional company, "Nilgiri Tea Exports":

```text
I work at Nilgiri Tea Exports. Write a friendly three-line message for our
office WhatsApp group inviting the accounts team to a farewell lunch for
our colleague Meera on Friday at 1 pm in the conference room.
```

```text
Response (example):
Hi team! We're hosting a farewell lunch for Meera this Friday at 1 pm in
the conference room. Come along to wish her well. Please reply here so we
can plan the food!
```

## Step 4: Follow up instead of starting over

The assistant remembers everything **within the same conversation**. If the
first reply is not quite right, reply to it as you would to a colleague:

```text
You: Make it a little more formal and mention it's vegetarian food.
You: Now give me a Hindi version as well.
You: Shorter please - two lines maximum.
```

Each follow-up builds on the previous reply. This is called **iterating**,
and it is usually faster than writing a perfect prompt in one go.

## Step 5: Retry and edit

Two more controls are worth knowing:

- **Retry (sometimes called regenerate)** asks the same question again. AI
  output varies from run to run, so you will often get a different version.
  This is handy for brainstorming names or subject lines.
- **Edit** lets you change a message you already sent and get a new reply
  from that point. Use it when you realise your original request was
  missing something important.

## Step 6: Attach a file (carefully)

Most assistants can read attached documents, images and spreadsheets. Try
it with a public, non-confidential document such as a published annual
report or a government circular.

```text
[attached: public-circular.pdf]

Summarise this circular in five bullet points for a branch manager. After
the bullets, list any deadlines it mentions with their dates, exactly as
written in the document.
```

Then **check the summary against the document**, especially numbers and
dates. Before attaching any work file, confirm your company's policy allows
that file in that tool.

## Step 7: Know when to start a new chat

Long conversations collect old instructions and topics that can confuse the
assistant. Start a **new chat** when:

- you switch to an unrelated task;
- the replies keep repeating an earlier mistake;
- the conversation has become very long.

You can copy the useful parts — your final instructions, a good example — into
the new chat so you do not lose your progress.

## Common first-day mistakes

| Mistake | Better habit |
| --- | --- |
| One-word prompts like "summarise" | Say who it is for, what you need, and how long |
| Accepting the first reply | Follow up, retry or edit until it fits |
| Copying output straight into an email | Read it, fix facts, adjust tone, then send |
| Pasting client data into a personal account | Use only approved tools and follow policy |
| Asking about yesterday's news without search | Paste the source, or use a tool with search enabled |

### Try it yourself

Open your company's approved assistant (or use only made-up details if you
do not have one yet). Take one task from the list you wrote at the end of
the previous lesson and:

1. Send a one-line prompt and save the reply.
2. Send a second, clearer prompt that names the reader, the purpose and the
   length. Compare the two replies.
3. Ask two follow-up questions to refine the better reply.
4. Press retry once and note how the new version differs.

Write one sentence on what made the biggest difference to the quality.
